# Доступные прошивки

- 1.0.0 — первая сохранённая версия, архивная.
- 1.1.4-diag — последняя диагностическая версия; таблица соседей и маршрутов выводится в UART каждые 45 секунд. OTA этой версии проверено на Homey Pro (2023).
- 1.1.5 — итоговая версия на той же базе, без периодического вывода таблиц. Управление чайником, восстановление маршрута и OTA сохранены. Команда `zigbee-info` остаётся для ручной диагностики основной UART-консоли.

`*-full.bin` записывается с адреса 0x0 при первой установке; `*-ota.bin` предназначен для обновления существующей OTA-разметки без очистки сопряжений.

Для передачи URL из Homey используйте короткую HTTPS-ссылку (консервативный лимит приложения — 48 байт). Длинный URL не проходил запись по Zigbee; короткий позволил успешно установить 1.1.4-diag.

Итоговая OTA-ссылка: https://tinyurl.com/2cyh5yj4
Диагностическая OTA-ссылка: https://tinyurl.com/25vtbzys

`f.bin` и `d.bin` в корне — копии итогового и диагностического OTA-образов для коротких путей загрузки. Промежуточные сборки удалены из текущего дерева, но доступны в истории Git.
