# REDMOND RK-G211S: мост Bluetooth LE → Zigbee

Эта прошивка превращает плату на **ESP32-C5-WROOM-1 N8R4** в локальный мост:

```text
REDMOND RK-G211S ← Bluetooth LE → ESP32-C5 ← Zigbee → координатор умного дома
```

Интернет, облако REDMOND и постоянно работающий компьютер не нужны. ESP должна
постоянно находиться в зоне Bluetooth чайника и получать питание через разъём
`UART` платы.

> Эта прошивка ESP32-C5 совместно с отдельным неофициальным приложением для
> Homey протестирована на **Athom Homey Pro (2023)**. Подключение к другим
> Zigbee-координаторам возможно, но состав доступных функций и их отображение
> зависят от конкретного хаба.

Приложение Homey находится в отдельном репозитории:
**[edsallo/homey-redmond-skykettle-zigbee](https://github.com/edsallo/homey-redmond-skykettle-zigbee)**.

## Совместимость с Zigbee-хабами

Прошивка **не привязана к Homey**. Она использует стандартный профиль Zigbee
Home Automation и стандартные кластеры:

| Кластер | Функция |
|---|---|
| Basic `0x0000` | Производитель `EdS Home`, модель `RK-G211S-ZB` |
| Identify `0x0003` | Идентификация устройства |
| On/Off `0x0006` | `On` — кипячение до 100 °C, `Off` — остановка |
| Thermostat `0x0201` | Текущая и заданная температура, режим `off/heat` |
| Temperature Measurement `0x0402` | Температура воды |

Любой Zigbee 3.0 координатор должен разрешить устройству присоединиться к сети.
Дальнейшее отображение зависит от программного обеспечения хаба:

- **Athom Homey Pro (2023):** это протестированная конфигурация; все проверенные
  функции предоставляет [отдельное приложение Homey](https://github.com/edsallo/homey-redmond-skykettle-zigbee).
- **Home Assistant ZHA:** стандартные кластеры обычно создают переключатель,
  датчик температуры и Climate. Конкретный интерфейс зависит от версии ZHA.
- **Zigbee2MQTT:** устройство присоединится, но до включения модели в официальный
  каталог может понадобиться сгенерированное внешнее определение устройства.
- **Другие хабы:** базовые On/Off и температура могут заработать автоматически;
  возможность задавать 40–100 °C зависит от поддержки кластера Thermostat.

Таким образом, радиопротокол универсальный, а красивый интерфейс и дополнительные
сценарии являются задачей интеграции конкретного хаба.

## Поддерживаемая плата

Готовый образ собран и проверен для платы:

- ESP32-C5-WROOM-1;
- Flash 8 MB, PSRAM 4 MB (`N8R4`);
- встроенный адресный RGB-светодиод и кнопка `BOOT` на общем GPIO27;
- два разъёма, подписанные `UART` и `USB`.

Для этой платы в проверенной процедуре прошивки используется разъём **UART**, а
не разъём `USB`. Подключите компьютер именно к разъёму с маркировкой `UART`.
Нужен кабель с передачей данных: кабель только для зарядки не подойдёт.

> Не записывайте готовый бинарный файл в другую модель ESP32. Для другой платы
> могут отличаться чип, объём памяти и GPIO кнопки/светодиода.

## Самый простой способ: готовый бинарный файл

Скачайте файл:

[`releases/redmond-rk-g211s-zigbee-bridge-v1.0.0.bin`](releases/redmond-rk-g211s-zigbee-bridge-v1.0.0.bin)

SHA-256 указан в [`releases/SHA256SUMS.txt`](releases/SHA256SUMS.txt).

Прошивается один файл по адресу `0x0`. При первой установке сначала выполняется
полная очистка Flash. Она удаляет старую Zigbee-сеть и адрес ранее запомненного
чайника.

## Прошивка в macOS с нуля

### 1. Установите Python

1. Откройте [python.org/downloads/macos](https://www.python.org/downloads/macos/).
2. Установите актуальный Python 3.
3. Откройте приложение **Terminal**.
4. Проверьте установку:

```bash
python3 --version
```

Должна появиться строка `Python 3.x.x`.

### 2. Установите esptool

```bash
python3 -m pip install --upgrade esptool
```

### 3. Найдите порт ESP

1. Подключите кабель к разъёму **UART** на плате.
2. Выполните:

```bash
ls /dev/cu.usbmodem* /dev/cu.usbserial* 2>/dev/null
```

Пример порта:

```text
/dev/cu.usbmodem5B420100151
```

Если вариантов несколько, отключите плату, повторите команду и сравните список.

### 4. Перейдите в папку со скачанным файлом

Если браузер сохранил файл в «Загрузки»:

```bash
cd ~/Downloads
```

### 5. Очистите память и запишите прошивку

Замените `PORT` реальным портом из шага 3:

```bash
python3 -m esptool --chip esp32c5 --port PORT erase-flash
python3 -m esptool --chip esp32c5 --port PORT write-flash 0x0 redmond-rk-g211s-zigbee-bridge-v1.0.0.bin
```

Пример:

```bash
python3 -m esptool --chip esp32c5 --port /dev/cu.usbmodem5B420100151 erase-flash
python3 -m esptool --chip esp32c5 --port /dev/cu.usbmodem5B420100151 write-flash 0x0 redmond-rk-g211s-zigbee-bridge-v1.0.0.bin
```

После сообщения об успешной проверке данных ESP перезапустится автоматически.

## Прошивка в Windows 10/11 с нуля

### 1. Установите Python

1. Откройте [python.org/downloads/windows](https://www.python.org/downloads/windows/).
2. Запустите установщик Python 3.
3. На первом экране обязательно отметьте **Add python.exe to PATH**.
4. Завершите установку.
5. Откройте **PowerShell** и проверьте:

```powershell
py --version
```

### 2. Установите esptool

```powershell
py -m pip install --upgrade esptool
```

### 3. Найдите COM-порт

1. Подключите кабель к разъёму **UART** платы.
2. Нажмите правой кнопкой по кнопке «Пуск» → **Диспетчер устройств**.
3. Откройте раздел **Порты (COM и LPT)**.
4. Запомните появившийся порт, например `COM5`.

Если раздел не появился, попробуйте другой кабель или USB-порт компьютера.

### 4. Перейдите в папку загрузок

```powershell
cd $HOME\Downloads
```

### 5. Очистите память и запишите прошивку

Замените `COM5` своим номером порта:

```powershell
py -m esptool --chip esp32c5 --port COM5 erase-flash
py -m esptool --chip esp32c5 --port COM5 write-flash 0x0 redmond-rk-g211s-zigbee-bridge-v1.0.0.bin
```

После успешной записи ESP перезапустится автоматически.

## Если esptool не может подключиться

1. Закройте Arduino IDE, Serial Monitor, PuTTY и другие программы, использующие
   COM/USB-порт.
2. Убедитесь, что кабель подключён к разъёму **UART**, а не `USB`.
3. Замените USB-кабель на заведомо поддерживающий передачу данных.
4. Переведите ESP в загрузчик вручную:
   - удерживайте `BOOT`;
   - коротко нажмите `RESET`;
   - отпустите `RESET`;
   - отпустите `BOOT`;
   - повторите команду esptool.
5. Если запись прерывается, добавьте низкую скорость перед командой:
   `--baud 115200`.

## Первое подключение ESP к Zigbee-хабу

После полной очистки ESP считается новым Zigbee-устройством и автоматически
пытается войти в открытую сеть.

1. Поставьте ESP рядом с Zigbee-хабом для первого подключения.
2. В интерфейсе хаба включите **добавление Zigbee-устройства / Permit join**.
3. Подайте питание на ESP или нажмите `RESET`.
4. Дождитесь появления устройства:
   - Manufacturer: `EdS Home`;
   - Model: `RK-G211S-ZB`.
5. После подключения ESP можно перенести ближе к чайнику и подключить к
   постоянному блоку питания через разъём `UART`.

Если ESP уже была в другой Zigbee-сети, удерживайте `BOOT` не менее 10 секунд.
После красного сигнала отпустите кнопку и снова включите добавление устройств
на хабе.

### Homey Pro

1. Установите [приложение REDMOND SkyKettle для Homey](https://github.com/edsallo/homey-redmond-skykettle-zigbee).
2. В Homey откройте **Устройства → + → REDMOND SkyKettle**.
3. Выберите `SkyKettle через Zigbee-мост`.
4. Выполните поиск. ESP должна быть в режиме присоединения.

### Home Assistant ZHA

1. Откройте **Настройки → Устройства и службы → Zigbee Home Automation**.
2. Нажмите **Добавить устройство**.
3. Сбросьте Zigbee-сеть ESP удержанием `BOOT` 10 секунд, если она уже была
   подключена к другому координатору.
4. Дождитесь завершения интервью устройства.

### Zigbee2MQTT

1. Нажмите **Permit join (All)** в интерфейсе Zigbee2MQTT.
2. Сбросьте Zigbee-сеть ESP удержанием `BOOT` 10 секунд, если требуется.
3. Дождитесь успешного interview модели `RK-G211S-ZB`.
4. Если Zigbee2MQTT пометит модель как неподдерживаемую, откройте вкладку
   **Dev console / Generate external definition**, сохраните созданное
   определение в `external_converters` и перезапустите Zigbee2MQTT.

## Подключение чайника к ESP

Это отдельное Bluetooth-сопряжение и оно не зависит от выбранного Zigbee-хаба.

1. Поставьте чайник на подключённую к сети базу.
2. Разместите ESP на расстоянии до 1–2 метров от чайника.
3. Подайте питание на ESP.
4. На чайнике удерживайте именно кнопку **«Вкл/Выкл»** около 5 секунд.
5. После трёх коротких звуковых сигналов отпустите кнопку.
6. ESP автоматически найдёт устройство с именем `RK-G211S`, авторизуется и
   сохранит его Bluetooth-адрес.
7. После подключения и к Zigbee, и к чайнику светодиод ESP станет зелёным.

Телефон, официальное приложение REDMOND и Bluetooth компьютера для этого не
нужны. Не подключайте чайник одновременно к другому Bluetooth-клиенту.

### Подключение другого чайника

Удерживайте `BOOT` 5–9 секунд. ESP забудет сохранённый Bluetooth-адрес и начнёт
поиск нового `RK-G211S`. Затем повторите процедуру с кнопкой «Вкл/Выкл» чайника.

## Кнопки ESP

| Действие | Результат |
|---|---|
| `RESET` | Перезагрузка ESP без удаления настроек |
| `BOOT` менее 5 секунд | Перезапуск поиска сохранённого чайника |
| `BOOT` 5–9 секунд | Забыть чайник и искать новый |
| `BOOT` 10 секунд и более | Удалить Zigbee-сеть и начать новое присоединение |

Отсчёт завершается после отпускания кнопки.

## RGB-индикатор ESP

| Цвет | Значение |
|---|---|
| Мигающий фиолетовый | ESP ещё не присоединилась к Zigbee-сети |
| Жёлтый | Zigbee подключён, но чайник по Bluetooth недоступен |
| Зелёный | Zigbee и чайник подключены |
| Красный | Подтверждение сброса Zigbee-сети |

Подсветка воды внутри чайника управляется самим чайником. Прошивка включает
автономное мерцание в простое с интенсивностью 50% от исходного значения.

## Что происходит при снятии чайника с базы

Bluetooth-модуль находится в чайнике и обесточивается вместе с ним. ESP замечает
разрыв, начинает быстрый поиск и после возврата чайника на базу авторизуется
повторно. Нагрев после снятия с базы автоматически не возобновляется. ESP
восстанавливает только безопасную автономную подсветку простоя.

## Управление

- Zigbee `On`: остановка текущего режима и обычное кипячение до 100 °C.
- Zigbee `Off`: остановка нагрева/поддержания.
- Запись `OccupiedHeatingSetpoint`: температура 40–100 °C и запуск программы.
- Смена активной температуры выполняется как `OFF → SetMode → ON`, поскольку
  чайник игнорирует прямую смену режима во время работы.

Известное ограничение голосовых мостов: если температурная программа уже
отображается как `On`, некоторые системы не отправляют повторную команду
«Включить/Вскипятить», считая устройство уже включённым.

## Самостоятельная сборка из исходников

Для сборки требуется ESP-IDF 5.5 или новее с поддержкой ESP32-C5. Зависимости
Zigbee и LED Strip загружаются ESP-IDF Component Manager автоматически.

```bash
. "$IDF_PATH/export.sh"
idf.py set-target esp32c5
idf.py build
idf.py -p PORT erase-flash flash monitor
```

Адреса отдельных образов:

| Адрес | Файл |
|---|---|
| `0x2000` | `build/bootloader/bootloader.bin` |
| `0x8000` | `build/partition_table/partition-table.bin` |
| `0x10000` | `build/redmond_zigbee_bridge.bin` |

REDMOND SkyKettle RK-G211S. BLE UART service:
