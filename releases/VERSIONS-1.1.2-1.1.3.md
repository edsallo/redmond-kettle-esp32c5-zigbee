# Версии для OTA

- `redmond-rk-g211s-zigbee-bridge-v1.1.2-ota.bin` — сохранённая версия 1.1.2, проверенная после повторного Zigbee-сопряжения: чтение температуры, запуск 55 °C и выключение. Восстановление маршрута при отключении роутера ещё требует проверки.
- `redmond-rk-g211s-zigbee-bridge-v1.1.3-diag-ota.bin` — диагностическая версия на той же базе. Добавлен вывод соседей и маршрутов Zigbee каждые 45 секунд и команда `zigbee-info` для основной UART-консоли. Логика управления чайником не менялась.

Оба файла подписаны одним ключом OTA. Они содержат только приложение, без NVS, паролей и привязки к конкретному чайнику. Обновление OTA сохраняет существующие сопряжения.

Снимки исходников соответствующих сборок находятся в `diagnostics/firmware-v1.1.2-saved` и `diagnostics/firmware-v1.1.3`. Полный цикл OTA пока не подтверждён практическим тестом.
